
- المصدر الوحيد لرقم الإصدار: `magasin/__init__.py` ← `__version__`
- كل EXE يُسمّى `Gestion_De_Stock_Chantier_v<X.Y.Z>.exe` داخل `releases\`
- **النسخ القديمة تُحفظ دائماً** — لا يمكن لإصدار موجود أن يُ overwritten
  (البناء يرفض ويطلب `--bump`)

- بجانب كل EXE ملف `<اسم>.version.txt` يوثّق رقم الإصدار وتاريخ البناء
- خصائص Windows (Properties → Details) تحمل رقم الإصدار واسم المطوّر

## 📖 دليل الاستخدام

### الشاشة الرئيسية
- **شريط علوي**: العنوان + مبدّل الورشة (+ لإنشاء ورشة جديدة) + اللغة (FR/EN/ع) + الوضع الليلي/النهاري + الإعدادات + حول
- **الشريط الجانبي**: المخازن السبعة (FORAGE، ELECTRIQUE، DIVERS، HSE، TOILE TAMIS، MECANIQUE، COOL ROOM) بألوانها الأصلية + "كل المخازن"
- **بطاقات الإحصائيات**: عدد المواد | الكمية الإجمالية | عدد المخازن | تنبيهات المخزون
- **الجدول**: مع الترتيب بالنقر على رؤوس الأعمدة + النقر المزدوج للتعديل + مفتاح Delete للحذف

### العمليات
| العملية | الطريقة | الاختصار |
|---|---|---|
| إضافة مادة | زر ➕ إضافة | `Ctrl+N` |
| تعديل | زر ✏️ أو نقر مزدوج على الصف | `Ctrl+E` |
| حذف | زر 🗑 (مع تأكيد) | `Delete` |
| بحث حي | حقل البحث أعلى الجدول | `Ctrl+F` |
| استيراد ملف Excel | زر 📥 (مع معاينة قبل التنفيذ) | `Ctrl+I` |
| تصدير Excel/CSV | زر 📤 | |
| نسخة احتياطية | زر 💾 | `Ctrl+B` |
| تحديث | زر 🔄 | `F5` |

### طباعة السندات (BTR / BSM / BRM) 🖨
1. **ضبط الترويسة مرة واحدة**: الإعدادات ⚙ ← «ترويسة السندات / الهوية» ← حمّل
   **الشعار** (ونائياً شعار ثانٍ للعميل/المشروع) + اسم المؤسسة/الورشة، النشاط،
   العنوان، الهاتف، الفاكس، البريد + **RC / NIF / NIS / RIB** → حفظ
   (البيانات تُخزَّن في قاعدة البيانات لكل جهاز).
2. في نافذة السند (دخول BTR / خروج BSM / إرجاع BRM): ابحث عن السند عبر
   **🔍** ثم اضغط **🖨 طباعة** — يُولَّد ملف **A4** يُفتح في المتصفح، ومنه
   **Ctrl+P** للطباعة أو **«حفظ كـ PDF»**.
3. محتوى الورقة: الشعار + الاسم + بيانات الاتصال + الأرقام الرسمية + الورشة،
   عنوان السند ورقمه وتاريخه وبياناته، جدول المادة (كود/وصف/وحدة/كمية/تموضع)،
   **إطارات توقيعات ثلاثية** (أعدّه / استلمه / شريف المشروع)، وتذييل مع اسم
   المطوّر. الترويسة تدعم العربية (RTL) والفرنسية/الإنجليزية.

### الاستيراد من ملف Excel
البرنامج يقرأ **كل أوراق المصنف** ويكشف الأعمدة تلقائياً (Article / Description /
UdM / Stock / Magasin)، مع دعم الصيغة القديمة (بيانات من الصف 6، الأعمدة G H J K F).
قبل أي تعديل تظهر **نافذة معاينة**: عدد السطور، التوزيع على المخازن، تحديد المخازن
غير المعروفة، ونمط الاستيراد (استبدال/إضافة). تُنشأ **نسخة احتياطية تلقائياً** قبل التنفيذ.

### التصدير
- **XLSX** بالتنسيق الأصلي (العناوين في الصف 5، البيانات من الصف 6) → قابل لإعادة الاستيراد
- **CSV** (توافق Excel العربي بترميز UTF-8 BOM)

## 🔧 الإصلاحات البرمجية مقارنة بالنسخة VBA

1. **✅ الحذف/التعديل المستهدف**: في VBA، إذا لم يُعثر على المادة كان الكود يطبّق العملية
   على الخلية النشطة العشوائية → **حذف صف خاطئ**. الآن كل عملية تتم بمعرّف (ID) محدّد،
   ورسالة واضحة إذا لم يُختر صف.
2. **✅ لا مسح قبل التحقق**: أمر الاستيراد القديم كان يمسح كل المخازن **قبل** فحص الملف
   المصدر (ملف خاطئ = فقدان بيانات). الآن: معاينة + تحقق + نسخة احتياطية تلقائية + معاملة (Transaction).
3. **✅ منع التكرار**: فريد مركّب (الرمز + المخزن + الورشة) في قاعدة البيانات نفسها.
4. **✅ تهيئة القوائم المنسدلة**: `ComboBox2` في النموذج القديم لم يكن يُملأ أبداً (خطأ).
5. **✅ متغيرات محدّدة الأنواع**: لا `Option Explicit` مفقود ولا متغيرات مجهولة (`a` بدل `i` في ListBox).
6. **✅ عدم إخفاء Excel**: لا مصيدة "Excel مخفي" إذا فشل تشغيل الماكرو.
7. **✅ كشف تلقائي للأعمدة**: بدل الأعمدة الثابتة G,H,J,K,F (فشل مع أي تغيير في الملف المصدر).
8. **✅ تصنيف المخازن الذكي**: يتجاهل الأخطاء الإملائية واللكنات (COOL ROM، ELECTRIQUE…)،
   والمخازن غير المعروفة تُعرض للمستخدم لتحديدها بدل إرسالها صفاً إلى DIVERS.

## ⬆ التحديث التلقائي (GitHub Releases)

يعمل التحديث التلقائي عبر **GitHub Releases**. للتفعيل:

1. أنشئ مستودعاً مجانياً على GitHub (مثال: `MRXDZ/Gestion-Stock-Chantier`)
2. ارفع كل إصدار كـ **Release** بـ **tag** يبدأ بـ `v` (مثال: `v2.15.0`) وأرفق ملف `Gestion_De_Stock_Chantier_vX.Y.Z.exe`
3. اضبط اسم المستودع في `magasin/updater.py` (`GITHUB_OWNER` / `GITHUB_REPO`) — أو من قاعدة البيانات (`update_owner` / `update_repo`)

**كيف يعمل:**
- عند التشغيل (بعد 6 ثوانٍ، مرة كل 6 ساعات) يتصل بـ `releases/latest` ويقارن الإصدار — **صامت تماماً عند عدم الإنترنت**
- زر «⬆ تحديث» للفحص اليدوي
- عند إتوفر نسخة أحدث: نافذة بالملاحظات + زر «تحميل وتثبيت» → يحمّل إلى `updates\` → سكربت `updater.bat` يستبدل الملف بعد إغلاق البرنامج (مع `.bak` احتياطي) → يعيد التشغيل

> **ملاحظة**: حساب GitHub غير الموثّق مسموح له بـ 60 طلب/ساعة — مرة واحدة عند كل تشغيل كافية تماماً.
